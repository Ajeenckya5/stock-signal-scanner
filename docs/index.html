A 24/7 desk for US and India names.

Named for the broad tape — the old wire that printed every name, not just the leaders. Autopilot keeps a BUY/SELL book on daily, monthly, and 5-minute candles. A walk-forward model scores whether a name leads its market over the next five sessions. Research software. Not a broker, and not advice.

Insights

24h / 1 month / 3 month / 6 month. Nifty 50, S&P 100, Nasdaq-100, or a liquid mix. Background pulse on SPY, QQQ, IWM, Nifty, Bank Nifty. Max names 18–160.

Intraday 5m

Session VWAP, opening range, volume POC, relative volume, cumulative delta while NYSE or NSE is open. Yahoo keeps about 60 sessions of 5-minute bars.

Walk-forward, not a backtest curve

HistGradientBoosting on 21 daily TA features. Label = beats that session’s same-market median over the next 5 days. Train years are embargoed 10 days from each test year (2019–2026). Pooled accuracy is 0.6 pp above the majority class and 1.2 pp above 21-day momentum. High-confidence calls (p ≥ 0.62 or ≤ 0.38) hit 59.7% with a +2.13 pp five-session spread — on 729 of 301k days.

That is a small research edge, not a live trading system. The desk blends the model into score only when confidence is high.

Run the live desk

GitHub Pages hosts this site. The scanner itself is Python — FastAPI, Yahoo Finance, the trained model on disk.

git clone https://github.com/Ajeenckya5/stock-signal-scanner.git
cd stock-signal-scanner
pip install -r requirements.txt
python app.py

Open http://localhost:8000 for the insights desk and /intraday for the 5-minute tape. Retrain with python pred_model.py or Universe → Train.
